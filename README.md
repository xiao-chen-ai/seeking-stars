## 下载安装

### macOS
下载 `觅星小臣-macOS.dmg`，双击挂载后拖入 **Applications** 即可。

### Windows
下载 `觅星小臣-Windows.zip`，解压后双击 **觅星小臣.exe** 运行。

> ⚠️ **如何关闭程序**：关闭浏览器窗口不等于关闭程序，后台服务会一直运行。
> - macOS：终端输入 `pkill -f 觅星小臣`
> - Windows：关闭命令行窗口，或按 `Ctrl+C`

> 🔐 **首次打开提示**：
> - macOS：提示"无法验证开发者"→ 右键 App → 打开
> - Windows：提示"Windows 已保护你的电脑"→ 点"更多信息" → "仍要运行"

## BOSS 职位采集 — 使用教程

通过浏览器脚本一键采集 BOSS 直聘上的职位信息，自动同步到桌面版「投递追踪」页面，无需手动输入。

### 1. 安装脚本猫插件

在浏览器中安装 **脚本猫**（Tampermonkey 兼容的用户脚本管理器）：

👉 [Chrome / Edge 安装教程](https://docs.scriptcat.org/docs/use/install/)

安装后在地址栏旁会出现 🐱 图标。

### 2. 安装采集脚本

| 脚本 | 安装链接 | 说明 |
|------|----------|------|
| 觅星小臣 - BOSS 海投 | [安装](https://scriptcat.org/zh-CN/script-show-page/5970) | 自动填充打招呼模板，批量投递 |
| 觅星小臣 - BOSS 职位收集器 | [安装](https://scriptcat.org/zh-CN/script-show-page/6435) | 一键采集职位信息，同步到桌面版 |

### 3. 一键采集

1. 确保 **觅星小臣桌面版已启动**
2. 打开 [BOSS 直聘](https://www.zhipin.com/) 更多详情页面
3. 脚本自动在页面添加操作按钮，点击即可一键采集

## AI 模型配置

桌面版内置硅基流动（SiliconFlow）接口，支持以下模型：

- **DeepSeek** — V4-Pro、V4-Flash、V3.2、R1
- **Qwen** — Qwen3.6、Qwen3.5
- **GLM** — GLM-5.1、GLM-4.7
- **Kimi** — Kimi-K2.6

### 获取 API Key

| 方式 | 说明 |
|------|------|
| 🎁 **没有API** | 打开应用点「找小臣」获取 |
| 🔑 **自己注册** | [硅基流动](https://cloud.siliconflow.cn/i/8Wt6MyMe) 注册即送免费额度 |

**配置路径**：桌面版右上角 → AI 设置 → 填入 API Key → 测试连接 → 保存。
